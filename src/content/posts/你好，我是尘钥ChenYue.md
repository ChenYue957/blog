# 你好，我是尘钥ChenYue

> 能坐下就不站着，能躺下就不坐着。

福建高三在读，**物化生**。英语是最头疼的科目，理科还行，但背单词属于折磨。

课余时间三件事：**打球**、**骑车**、**折腾设备**。建这个博客主要是给自己留个档——坑踩得太多，不记下来下次还得再踩一遍。

---

## 从什么时候开始的

初中第一次自己装系统，后来摸到服务器、虚拟化、软路由，一路靠搜索和试错学过来。

现在家里两台 PVE 主机跑满服务，NAS 互相备份，能自动化的都接进了 HomeAssistant。都不算精通，但足够把自己想要的东西搭出来。

---

## 现在在折腾什么

### 🖥️ 家里云

**两台 PVE 主机**，分工明确：

表格

| 节点      | 职责                            |
| ------- | ----------------------------- |
| **主节点** | Docker 容器、MC 生电服务器（三年无休）、奇怪脚本 |
|         | 主 NAS：飞牛 OS，RAID0 双盘 + 百度网盘同步 |
| **备节点** | 备 NAS：定期同步                    |

**网络层**：软路由折腾过 OpenWrt、EZOP，现在稳定运行。IPv6 优先，内网穿透备用。

> 数据焦虑晚期患者的自我安慰：双机 + 云盘 + 冷备，应该不至于全丢了吧。

---

### 🏠 智能家居

HomeAssistant 深度用户。灯、空调（离谱的格力空调也接入米家）、传感器，能联网的、有蓝牙 Mesh 的都塞进去了。

**原则**：能自动的绝不手动，能语音的绝不起身。

---
