课余时间三件事：**打球**、**骑车**、**折腾设备**。建这个博客主要是给自己留个档——坑踩得太多，不记下来下次还得再踩一遍。

## 从什么时候开始的

初中第一次自己装系统，后来摸到服务器、虚拟化、软路由，一路靠搜索和试错学过来。

现在家里两台 PVE 主机跑满服务，NAS 互相备份，能自动化的都接进了 Home Assistant。都不算精通，但足够把自己想要的东西搭出来。

## 现在在折腾什么

### ⚡ 半吊子的技术流

**🖥️ 家里云**

两台 PVE 主机分工明确：

| 节点 | 职责 |
| ---- | ---- |
| **主节点** | Docker 容器、MC 生电服务器（三年无休）、奇怪脚本；主 NAS：飞牛 OS，RAID0 双盘 + 百度网盘同步 |
| **备节点** | 备 NAS：TrueNAS，定期同步主节点数据 |

**网络层**：软路由折腾过 iKuai、OpenWrt、EZOP，现在稳定运行。IPv6 优先，内网穿透备用。

> 数据焦虑晚期患者的自我安慰：双机 + 云盘 + 冷备，应该不至于全丢了吧。

**📱 数码与刷机**

手机、手表、路由器、电视盒子，能刷第三方系统的都折腾过。喜欢研究硬件参数，不考虑功耗和电费，最后往往选择“能用就行”。

**🖥️ 装机**

图吧垃圾佬精神，享受捡垃圾和极限压缩预算的快感，能用就行。

**🤖 大模型与 AI**

玩过 AI 绘图，现在主要折腾 Koishi QQ 机器人，给群友整点活。

**🧩 魔方**

高阶及异形都玩，手头有几个异形魔方吃灰中。

**🏠 智能家居**

Home Assistant 深度用户。灯、空调（离谱的格力空调也接入米家）、传感器，能联网的、有蓝牙 Mesh 的都塞进去了。

> 原则：能自动的绝不手动，能语音的绝不起身。
